Unlock PDF

Remove the password from bank statements and tax PDFs before you send them to your CA. The file is unlocked on this device and never uploaded.

Case-sensitive. It's tried on every PDF you add. If one file uses a different password, you can type it on that file.

Files

    Keep this on your iPhone: tap Share in Safari, then Add to Home Screen. It opens like an app.

    How it works

    1. Type the password you use to open the statement.
    2. Choose the PDFs. Pick several at once if they share a password.
    3. Send the unlocked copy to your CA on WhatsApp or Mail, or save it to Files.

    Works with AES-256, AES-128 and RC4 protected PDFs, and also removes print and copy restrictions. Your original file stays as it is.
